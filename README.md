# python-machine-learning
Developed a handwritten digit recognition model using Python, TensorFlow/Keras, and Neural Networks to recognize and classify digits (0–9) from the MNIST dataset.

Dataset:
This project uses MNIST handwritten dataset.
Training images:60000 and Testing Images:10000
input feautres:784 pixels per image
image dimension: 28 x 28 pixels
Number of classes:10 (digits 0-9)

TechStack:
Python, Numpy, Matplotlib, Tensorflow, scikit learn

Evaluation:
Evaluated using: accuracy, precision, F1-score.
